# 素材类型路由

先识别素材关系，再读取唯一对应的粗剪子技能。公共的媒体探测、声学验收、字幕、样式和交付规则不复制进子技能。

| `material_type` | 识别条件 | 粗剪入口 | 包装入口 | 当前状态 |
|---|---|---|---|---|
| `single_speaker` | 一位说话人承担全部内容，且原始输入为单个文件 | [`../子技能/粗剪/单人口播.md`](../子技能/粗剪/单人口播.md) | [`../子技能/包装/单人口播.md`](../子技能/包装/单人口播.md) | 原始素材全流程支持 |
| `single_speaker_multi_source` | 同一人、同次主题录制拆成多个原文件 | [`../子技能/粗剪/单人口播.md`](../子技能/粗剪/单人口播.md) | [`../子技能/包装/单人口播.md`](../子技能/包装/单人口播.md) | 人工粗剪 XML 可在原工程加字幕；已有 source-aware 冻结粗剪可交剪映；原始多文件 AI 粗剪与新建 Final Cut 多 asset 终版停止 |
| `single_subject_interview` | 一位学员是唯一内容主体；提问者仅引导且原声全删 | [`../子技能/粗剪/学员好评.md`](../子技能/粗剪/学员好评.md) | [`../子技能/包装/学员好评.md`](../子技能/包装/学员好评.md) | 支持 |
| `dual_speaker` / `multi_speaker` | 两位或更多说话人都承担不可删除的观点 | [`../子技能/粗剪/双人口播.md`](../子技能/粗剪/双人口播.md) | 无 | 只识别并停止 |
| `unknown` | 无法可靠判断说话人与内容关系 | 无 | 无 | 停止 |

同一人分成多个原文件，内容关系仍属于单人口播，不能因为文件数量变成多人素材；工程路由另记为 `single_speaker_multi_source`，用于触发当前能力边界。现行下游能按 `source_id` 生成粗剪 XML 和剪映草稿；人工粗剪 XML 加字幕则保留输入工程已有的多素材资源。原始多文件还缺少统一的 P0 素材集锁、逐源 P1T 词轴、跨源 P1 声学验收和新建 Final Cut 终版多 asset 闭环。因此没有人工粗剪 XML 或已有 source-aware 冻结粗剪时，只完成逐文件技术探测、素材关系和缺口报告后停止；已有 source-aware 冻结粗剪若要求新建 Final Cut 终版也停止。不得临时拼工作区冒充全流程支持。学员采访里出现提问者声音，也不能因此误判为双人口播；关键是提问者是否承担成片内容。

双人口播目前没有足够的“AI 初稿—用户精调”成对证据和说话人保持契约。不得把单人口播规则硬套后声称已经支持。收到这种素材时，只完成技术属性和说话人识别，列出缺少的样本与规则后停止。
