# 学员好评包装

这是 `single_subject_interview` 粗剪完成并通过内部冻结后的包装入口。字幕文字、对齐、横竖屏样式和平台交付仍执行主 Skill 的 P2–P6；本文件只规定好评内容特有的包装边界。

## 真实性先于热闹

- 基础字幕只写学员真实保留的声音；不能把提问者原话、编辑概括或课程宣传语伪装成学员原话。
- 需要补足已删问题的语境时，使用独立的“问题语境桥”标题，并保持问答范围、人物立场与限制条件。
- 课程价值、学员变化和结果数据必须能回指粗剪中的证言；包装不能替证据扩大结论。

## 包装节点

优先在以下位置使用少量章节标题、重点字或证据提示：目标人群的真实问题、课程介入方式、前后变化、具体业务结果、限制条件和最终评价。学员只是笼统说“很好”时，不用强包装把它伪造成强证据。

课程名、方法名、结果数字和前后对比可以成为重点候选；最终是否上色仍由 P5 显式清单决定。基础字幕默认纯白，不能因为这是好评就每张都强调。

音乐、音效、花字和复杂视觉效果只有用户明确授权时才添加。它们不得掩盖停顿、改写情绪或让学员语气显得比原声更绝对。
