# 双人口播粗剪：当前停止点

本文件用于识别“两位说话人都承担成片观点”的素材，防止它被误套为单人口播或“删除提问者”的学员好评。

当前不进入自动粗剪。原因不是双人口播一定难剪，而是 Skill 尚缺少以下用户证据：

1. 至少两组同类型 AI 初稿与用户精调 XML；
2. 说话人轮次、抢话、接话和反应声的保留方法；
3. 双方观点冲突、互证与来回承接的排序方法；
4. 哪些问答可压缩、哪些必须保留对方语境；
5. 双人声学切口和字幕说话人标记的验收样本。

识别为本类型后，只报告素材属性、说话人数和停止原因。不得删除其中一方、不得假装按单人口播剪完，也不得把实验结果登记为生产规则。
