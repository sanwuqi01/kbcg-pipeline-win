# 样本库数据说明（DATA_LICENSE）

## 这是什么

`样本库/` 下的 FCPXML 是「AI 初稿 — 用户终版」成对样本，是本 Skill
学习真实剪辑偏好的核心资产。`成对样本清单.json` 以 SHA-256 锚定每一对，
**修改任何一个字节都会使哈希校验失败**，因此样本文件本身不可脱敏改写。

## 隐私边界

样本时间线源自真实口播/采访素材，字幕文本为真实人声的 ASR 转写，
包含说话人对同事/客户的自然称呼。若你的使用场景要求完全匿名：

- 可整体删除 `样本库/` 目录（Skill 仍可运行，但「开工前选 2–3 组
  成对样本学习」的工序会退化为无真值参考，P1 决策质量下降）；
- 或用你自己的素材重建样本库（按 `成对样本清单.json` 的 schema 登记）。
